# About
This is a blog site hosted at emilycdecker.com from github pages.
Only users mjdiloreto and ecdecker have access.
mjdiloreto is codeowner of the site and repository, ecdecker is the owner for content. 

Index is a profile page for Emily Decker, and Ph.D student at Duke studying Environmental Economics & Policy. Interested in clean energy transitions, environmental health impacts, climate change resilience, as well as the role of climate finance to address these issues. Authoring can only be done by site owners, but we could use pagescms.
