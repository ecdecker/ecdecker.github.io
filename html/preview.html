A quieter way
to put things on paper.

Folio is a small, monochrome system for editorial product work. Bone paper, hairline borders, one serif marquee — and nothing else asking for attention.

  • One warm neutral. One ink. No accent colors.
  • Instrument Serif for marquee, Inter for everything else.
  • 1px hairlines carry every separation.
  • A single four-point spark, used sparingly.

Plate I — Reading shelf

Three quiet rules.

Folio is small on purpose. The whole system runs on a handful of decisions that never get spent on decoration.

Set in serif.

Headlines live in Instrument Serif from 32 to 96 pixels. Body in Inter 400/500. Two families, no exceptions.

01 Type

Built on hairlines.

Every divider, card edge, input outline, and table line is a single Mist pixel. Depth is contrast, not shadow.

02 Structure

Reduced to one mark.

A four-point spark is the only ornament permitted. It signs the wordmark, divides sections, and otherwise stays out of the way.

03 Mark

One leaf, one voice.

Tokens, type, and palette in a single specimen. Nothing changes on hover that doesn't need to change.
