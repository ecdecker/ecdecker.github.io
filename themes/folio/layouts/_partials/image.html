{{- /* Optimized responsive image. Emits AVIF with a WebP fallback and no original-format source. The original-format that this pattern usually carries adds no capability — a browser that skips the modern sources matches the fallback, which is already that format — while costing the most bytes of anything on the page. Params: resource (resource) an already-resolved image, e.g. a page-bundle sibling. Takes precedence over src. src (string) path under assets/, with or without leading / alt (string, required) empty string for decorative images sizes (string) media-condition sizes attribute. Defaults to 100vw, which over-fetches — always pass a real value. class (string) classes for the widths (slice) candidate widths; capped to the source width quality (int) encoder quality; overrides the measured per-image value from data/imagequality.json eager (bool) true for the one above-the-fold image fit (string) "resize" (default) or "fill" ratio (string) target aspect ratio for fit=fill, e.g. "16:9" Example: {{ partial "image.html" (dict "src" "images/plate.png" "alt" "Field site" "sizes" "(min-width: 880px) 640px, 100vw") }} */ -}} {{- $cfg := site.Params.images | default dict -}} {{- $src := strings.TrimPrefix "/" .src -}} {{- $alt := .alt | default "" -}} {{- $class := .class | default "" -}} {{- $sizes := .sizes | default ($cfg.sizes | default "100vw") -}} {{- $quality := .quality | default ($cfg.quality | default 45) -}} {{- $fit := .fit | default "resize" -}} {{- $ratio := .ratio | default "" -}} {{- $eager := .eager | default false -}} {{- $widths := .widths | default ($cfg.widths | default (slice 320 480 640 800 1200)) -}} {{- $resolved := .resource -}} {{- if not $resolved }}{{ $resolved = resources.Get $src }}{{ end -}} {{- with $resolved }} {{- $img := . -}} {{- /* Per-image quality, from data/imagequality.json. One global q is a bad trade: holding a fixed perceptual floor (SSIM 0.92) takes q25 on a soft gradient and q70 on a fine texture, so a single value either wastes bytes on the easy images or wrecks the hard ones. Measured per image by `npm run site -- images`, which on this corpus is 1.70x fewer bytes than the cheapest global q clearing the same floor — a bigger win than the AVIF-vs-WebP choice itself. Keys are source paths relative to assets/ or content/. Getting from a resource back to that path differs by origin, and both branches below were verified empirically on Hugo 0.164: * A global asset's .Name is already "/images/plate.png". Direct lookup. * A page-bundle sibling's .Name is the bare "plate.png", so it needs the owning page's directory — and the resource cannot be asked for it. The obvious candidates are all wrong: .Key and .RelPermalink follow the page's slug, not its source path, and the global `page` is the page being *rendered*, which inside a render hook is the list page whenever content is reached through .Summary first. That last one is worse than wrong, it is nondeterministic: whichever context renders the content first wins the cache, so the same source could build at two different q. Instead the pages are walked once — where .File is the page's own file and therefore trustworthy — to index every bundled image by published path, which is resource-intrinsic. An explicit quality param still wins over all of this, and anything unmeasured falls back to the global default. */ -}} {{- if not $.quality }} {{- $table := dict -}} {{- /* hugo.Data, not site.Data: the latter is deprecated in 0.156+ and builds must stay warning-free. */ -}} {{- with hugo.Data.imagequality }}{{ with .images }}{{ $table = . }}{{ end }}{{ end -}} {{- $entry := "" -}} {{- if hasPrefix $img.Name "/" -}} {{- $entry = index $table (strings.TrimPrefix "/" $img.Name) -}} {{- else -}} {{- $byPath := site.Store.Get "folioImageQuality" -}} {{- if not $byPath -}} {{- $sc := newScratch -}} {{- range $p := site.Pages -}} {{- with $p.File -}} {{- $dir := .Dir -}} {{- range $r := $p.Resources.ByType "image" -}} {{- with index $table (strings.TrimPrefix "/" (path.Join $dir $r.Name)) -}} {{- $sc.SetInMap "m" $r.Key . -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Published complete, never half-built: a reader either finds nothing here and builds its own copy, or finds all of it. */ -}} {{- $byPath = $sc.Get "m" | default dict -}} {{- site.Store.Set "folioImageQuality" $byPath -}} {{- end -}} {{- $entry = index $byPath $img.Key -}} {{- end -}} {{- with $entry }} {{- if reflect.IsMap . -}} {{- with .quality }}{{ $quality = int . }}{{ end -}} {{- else -}} {{- $quality = int . -}} {{- end -}} {{- end }} {{- end }} {{- /* Never upscale: a width above the source invents pixels and costs real bytes. Always keep at least one candidate. */ -}} {{- $usable := slice -}} {{- range $widths }} {{- if le . $img.Width }}{{ $usable = $usable | append . }}{{ end }} {{- end }} {{- if not $usable }}{{ $usable = slice $img.Width }}{{ end }} {{- /* fit=fill needs a ratio; without one it silently crops to nothing useful, so fall back to a plain resize and say so. */ -}} {{- if and (eq $fit "fill") (not $ratio) }} {{- warnf "image.html: fit=fill needs a ratio for %s — resizing instead." $src }} {{- $fit = "resize" }} {{- end }} {{- $rw := 0 }}{{- $rh := 0 }} {{- if eq $fit "fill" }} {{- $parts := split $ratio ":" -}} {{- $rw = index $parts 0 | int -}} {{- $rh = index $parts 1 | int -}} {{- end }} {{- /* Grayscale sources and the AVIF encoder. Hugo keeps a source's colour model all the way through Resize/Fill and every images.* filter, so a 16-bit grayscale PNG reaches the AVIF encoder as image.Gray16, hits its encodeGray path and fails: error calling Resize: failed to resize image "...": encodeGray: Failed to add image to encoder: Encoding of color planes failed That aborts the WHOLE build, not just the one image. 8-bit gray (and gray+alpha, and 16-bit RGB) all encode fine — only Gray16 trips it. Verified on Hugo 0.164.0. It is also cache-masked: once any successful derivative of the image exists in resources/_gen, a warm rebuild can pass and then fail on a cold CI checkout. So this is guarded, not just tested. The fix is to shed the grayscale colour model. No lossless route exists: PNG preserves it, and Overlay/Mask/Text/Brightness/ Saturation/Colorize/Dither/Padding all leave it intact. Only a re-encode through a format with no grayscale representation works, so the ladder is rebuilt off a WebP q100 intermediate. Measured, cheapest q holding SSIM >= 0.92, AVIF-via-round-trip vs just dropping the AVIF and shipping WebP: smooth gray plate 640px 3304 -> 2730 B round-trip 1.21x smaller 800px 4778 -> 3430 B 1.39x 1200px 10928 -> 5907 B 1.85x gray parchment 640px 43230 -> 38319 B 1.13x 800px 60096 -> 64135 B WebP-only 1.06x smaller 1200px 154050 -> 180794 B 1.17x So neither wins everywhere, but the round-trip's worst case is +17% while WebP-only's worst case is +85%. Bytes are the priority here, so take the bounded downside. (A JPEG q100 intermediate measured within 1-3% of WebP q100 either way; WebP keeps the pipeline to the two codecs it already ships.) */ -}} {{- $avif := slice }}{{- $webp := slice }}{{- $largest := "" -}} {{- $avifOK := true -}} {{- $needsRGB := false -}} {{- range $w := $usable }} {{- $spec := "" -}} {{- if eq $fit "fill" -}} {{- $spec = printf "%dx%d Center" $w (div (mul $w $rh) $rw) -}} {{- else -}} {{- $spec = printf "%dx" $w -}} {{- end -}} {{- $p := "" -}} {{- if eq $fit "fill" -}} {{- $p = $img.Fill (printf "%s webp q%d" $spec $quality) -}} {{- else -}} {{- $p = $img.Resize (printf "%s webp q%d" $spec $quality) -}} {{- end -}} {{- /* Direct AVIF first — the only path a normal image ever takes, and it costs nothing extra because this derivative ships anyway. $needsRGB latches on the first failure so later widths skip straight to the round-trip instead of re-failing. The emptiness check is not paranoia. A failed AVIF transform leaves a ZERO-BYTE entry in the image cache, and on the next build try() reads that back as a success — so a warm rebuild silently publishes a 0 B .avif, the wins over the WebP, and the image renders as nothing. It compounds: each rebuild poisons one more width. Observed on Hugo 0.164 as 3 of 4 widths at 0 B after three warm builds, with the build still exiting 0. Treating an empty payload as a failure is what makes this correct on a warm cache, not just on CI. */ -}} {{- $a := "" -}} {{- if not $needsRGB -}} {{- $t := "" -}} {{- if eq $fit "fill" -}} {{- $t = try ($img.Fill (printf "%s avif q%d" $spec $quality)) -}} {{- else -}} {{- $t = try ($img.Resize (printf "%s avif q%d" $spec $quality)) -}} {{- end -}} {{- if $t.Err -}} {{- $needsRGB = true -}} {{- else if not (len $t.Value.Content) -}} {{- $needsRGB = true -}} {{- else -}} {{- $a = $t.Value -}} {{- end -}} {{- end -}} {{- if $needsRGB -}} {{- $base := "" -}} {{- if eq $fit "fill" -}} {{- $base = $img.Fill (printf "%s webp q100" $spec) -}} {{- else -}} {{- $base = $img.Resize (printf "%s webp q100" $spec) -}} {{- end -}} {{- $t := try ($base.Resize (printf "%dx avif q%d" $w $quality)) -}} {{- /* Nested rather than `or`, so .Value is never touched when .Err is set — this must not depend on argument short-circuiting. */ -}} {{- if $t.Err -}} {{- /* Round-trip did not help either: ship WebP only rather than kill the build. Every browser with AVIF also has WebP. */ -}} {{- $avifOK = false -}} {{- else if not (len $t.Value.Content) -}} {{- $avifOK = false -}} {{- else -}} {{- $a = $t.Value -}} {{- end -}} {{- end -}} {{- with $a }}{{ $avif = $avif | append (printf "%s %dw" .RelPermalink $w) }}{{ end -}} {{- $webp = $webp | append (printf "%s %dw" $p.RelPermalink $w) -}} {{- $largest = $p -}} {{- end }} {{- if not $avifOK }} {{- warnf "image.html: %q cannot be AVIF-encoded even after an RGB round-trip — shipping WebP only." (or $src $img.Name) }} {{- end }} {{- if and $avifOK $avif }} {{- end }} {{- else }} {{- errorf "image.html: no local asset at %q" $src }} {{- end }}
