{{- /* Optimized responsive image. Emits AVIF with a WebP fallback and no original-format source. The original-format that this pattern usually carries adds no capability — a browser that skips the modern sources matches the fallback, which is already that format — while costing the most bytes of anything on the page. Params: resource (resource) an already-resolved image, e.g. a page-bundle sibling. Takes precedence over src. src (string) path under assets/, with or without leading / alt (string, required) empty string for decorative images sizes (string) media-condition sizes attribute. Defaults to 100vw, which over-fetches — always pass a real value. class (string) classes for the widths (slice) candidate widths; capped to the source width quality (int) encoder quality; overrides the measured per-image value from data/imagequality.json eager (bool) true for the one above-the-fold image fit (string) "resize" (default) or "fill" ratio (string) target aspect ratio for fit=fill, e.g. "16:9" Example: {{ partial "image.html" (dict "src" "images/plate.png" "alt" "Field site" "sizes" "(min-width: 880px) 640px, 100vw") }} */ -}} {{- $cfg := site.Params.images | default dict -}} {{- $src := strings.TrimPrefix "/" .src -}} {{- $alt := .alt | default "" -}} {{- $class := .class | default "" -}} {{- $sizes := .sizes | default ($cfg.sizes | default "100vw") -}} {{- $quality := .quality | default ($cfg.quality | default 45) -}} {{- $fit := .fit | default "resize" -}} {{- $ratio := .ratio | default "" -}} {{- $eager := .eager | default false -}} {{- $widths := .widths | default ($cfg.widths | default (slice 320 480 640 800 1200)) -}} {{- $resolved := .resource -}} {{- if not $resolved }}{{ $resolved = resources.Get $src }}{{ end -}} {{- with $resolved }} {{- $img := . -}} {{- /* Per-image quality, from data/imagequality.json. One global q is a bad trade: holding a fixed perceptual floor (SSIM 0.92) takes q25 on a soft gradient and q70 on a fine texture, so a single value either wastes bytes on the easy images or wrecks the hard ones. Measured per image by tools/measure-image-quality.py --write-data, which on this corpus is 1.70x fewer bytes than the cheapest global q clearing the same floor — a bigger win than the AVIF-vs-WebP choice itself. Keys are source paths relative to assets/ or content/. Getting from a resource back to that path differs by origin, and both branches below were verified empirically on Hugo 0.164: * A global asset's .Name is already "/images/plate.png". Direct lookup. * A page-bundle sibling's .Name is the bare "plate.png", so it needs the owning page's directory — and the resource cannot be asked for it. The obvious candidates are all wrong: .Key and .RelPermalink follow the page's slug, not its source path, and the global `page` is the page being *rendered*, which inside a render hook is the list page whenever content is reached through .Summary first. That last one is worse than wrong, it is nondeterministic: whichever context renders the content first wins the cache, so the same source could build at two different q. Instead the pages are walked once — where .File is the page's own file and therefore trustworthy — to index every bundled image by published path, which is resource-intrinsic. An explicit quality param still wins over all of this, and anything unmeasured falls back to the global default. */ -}} {{- if not $.quality }} {{- $table := dict -}} {{- /* hugo.Data, not site.Data: the latter is deprecated in 0.156+ and builds must stay warning-free. */ -}} {{- with hugo.Data.imagequality }}{{ with .images }}{{ $table = . }}{{ end }}{{ end -}} {{- $entry := "" -}} {{- if hasPrefix $img.Name "/" -}} {{- $entry = index $table (strings.TrimPrefix "/" $img.Name) -}} {{- else -}} {{- $byPath := site.Store.Get "folioImageQuality" -}} {{- if not $byPath -}} {{- $sc := newScratch -}} {{- range $p := site.Pages -}} {{- with $p.File -}} {{- $dir := .Dir -}} {{- range $r := $p.Resources.ByType "image" -}} {{- with index $table (strings.TrimPrefix "/" (path.Join $dir $r.Name)) -}} {{- $sc.SetInMap "m" $r.RelPermalink . -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Published complete, never half-built: a reader either finds nothing here and builds its own copy, or finds all of it. */ -}} {{- $byPath = $sc.Get "m" | default dict -}} {{- site.Store.Set "folioImageQuality" $byPath -}} {{- end -}} {{- $entry = index $byPath $img.RelPermalink -}} {{- end -}} {{- with $entry }} {{- if reflect.IsMap . -}} {{- with .quality }}{{ $quality = int . }}{{ end -}} {{- else -}} {{- $quality = int . -}} {{- end -}} {{- end }} {{- end }} {{- /* Never upscale: a width above the source invents pixels and costs real bytes. Always keep at least one candidate. */ -}} {{- $usable := slice -}} {{- range $widths }} {{- if le . $img.Width }}{{ $usable = $usable | append . }}{{ end }} {{- end }} {{- if not $usable }}{{ $usable = slice $img.Width }}{{ end }} {{- /* fit=fill needs a ratio; without one it silently crops to nothing useful, so fall back to a plain resize and say so. */ -}} {{- if and (eq $fit "fill") (not $ratio) }} {{- warnf "image.html: fit=fill needs a ratio for %s — resizing instead." $src }} {{- $fit = "resize" }} {{- end }} {{- $rw := 0 }}{{- $rh := 0 }} {{- if eq $fit "fill" }} {{- $parts := split $ratio ":" -}} {{- $rw = index $parts 0 | int -}} {{- $rh = index $parts 1 | int -}} {{- end }} {{- $avif := slice }}{{- $webp := slice }}{{- $largest := "" -}} {{- range $w := $usable }} {{- $spec := "" -}} {{- if eq $fit "fill" -}} {{- $spec = printf "%dx%d Center" $w (div (mul $w $rh) $rw) -}} {{- else -}} {{- $spec = printf "%dx" $w -}} {{- end -}} {{- $a := "" }}{{- $p := "" -}} {{- if eq $fit "fill" -}} {{- $a = $img.Fill (printf "%s avif q%d" $spec $quality) -}} {{- $p = $img.Fill (printf "%s webp q%d" $spec $quality) -}} {{- else -}} {{- $a = $img.Resize (printf "%s avif q%d" $spec $quality) -}} {{- $p = $img.Resize (printf "%s webp q%d" $spec $quality) -}} {{- end -}} {{- $avif = $avif | append (printf "%s %dw" $a.RelPermalink $w) -}} {{- $webp = $webp | append (printf "%s %dw" $p.RelPermalink $w) -}} {{- $largest = $p -}} {{- end }} {{- else }} {{- warnf "image.html: no asset at %q — image omitted." $src }} {{- end }}
