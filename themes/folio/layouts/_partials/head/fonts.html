{{- /* Instrument Serif (display) + Inter (body) — the only two families the system permits. Self-hosted rather than fetched from Google. Same bytes, but it removes two third-party origins (fonts.googleapis.com, fonts.gstatic.com) and with them two DNS + TCP + TLS handshakes, and it breaks the serialized dependency where the browser had to fetch and parse Google's CSS before it could even discover the font URLs. The old "shared cache" argument for Google Fonts no longer applies: browsers have partitioned the HTTP cache per-origin since ~2020, so a visitor gains nothing from having downloaded Inter on some other site. The @font-face rules are inlined rather than left in main.css so the URLs are discoverable in the first response, and each file is fingerprinted so it can be served immutable. Only the `latin` subsets are shipped. That range covers U+0000-00FF plus Œœ, smart punctuation and €, which is the whole of English and French — including œuvre and every accent in the fr translation. A language needing latin-ext, Greek or Cyrillic would need its subset added here. The two Instrument Serif faces are re-cut by tools/subset-fonts.py, which strips TrueType hinting and keeps every glyph — 31% smaller with identical coverage, advance widths and vertical metrics. See that script for why the character set is not cut instead. The two font-display values differ on purpose. Inter is `swap`: it sets every word of body text, so the text must be readable immediately and must not be abandoned to a fallback. The serif is `optional`, which is a real design concession and should be understood before anyone changes it back. `optional` gives the browser a ~100ms block period and no swap period: if the file is not ready in time, the fallback stack in tokens.css (Cormorant Garamond → Times New Roman) is used for the lifetime of that page load, and on a slow connection the browser may abandon the download entirely. In practice a first-time visitor sees the headline, the wordmark and pull quotes set in the fallback serif, and gets Instrument Serif from the second page view onward, once it is cached. What that buys: a first visit can cost 0 bytes of serif instead of 29,768, and layout shift is zero either way — the font is applied before first paint or not at all, so nothing reflows mid-read. What it costs: DESIGN.md asks for one serif marquee, and on a first visit that marquee is not Instrument Serif. To revert, set both serif faces back to `swap` and re-add their preload links above. Set params.folio.remoteFonts = false to opt out entirely and fall back to the local stacks declared in tokens.css. */ -}} {{- $remote := true -}} {{- with site.Params.folio -}} {{- if isset . "remotefonts" -}} {{- $remote = .remoteFonts -}} {{- end -}} {{- end -}} {{- if $remote -}} {{- /* Inter ships as a single variable file covering the whole 100-900 axis, so 400/500/600 cost one download, not three. */ -}} {{- $inter := resources.Get "fonts/inter-latin-var.woff2" | fingerprint -}} {{- $serif := resources.Get "fonts/instrument-serif-latin.woff2" | fingerprint -}} {{- $serifItalic := resources.Get "fonts/instrument-serif-latin-italic.woff2" | fingerprint -}} {{- /* Only Inter is preloaded. It carries every word of body text, so it is worth fetching eagerly; fonts are always fetched in CORS mode, so crossorigin is required even same-origin or the preload is wasted and the file fetched twice. The two serif faces are deliberately NOT preloaded. rel=preload is a mandatory fetch directive: preloading them would commit the browser to 29,768 bytes before font-display: optional ever gets a say, which would keep the no-layout-shift benefit but throw away the bandwidth saving that is the whole point of `optional`. */ -}} {{- end -}}
