{{- /* Instrument Serif (display) + Inter (body) — the only two families the system permits. Self-hosted rather than fetched from Google. Same bytes, but it removes two third-party origins (fonts.googleapis.com, fonts.gstatic.com) and with them two DNS + TCP + TLS handshakes, and it breaks the serialized dependency where the browser had to fetch and parse Google's CSS before it could even discover the font URLs. The old "shared cache" argument for Google Fonts no longer applies: browsers have partitioned the HTTP cache per-origin since ~2020, so a visitor gains nothing from having downloaded Inter on some other site. The @font-face rules are inlined rather than left in main.css so the URLs are discoverable in the first response, and each file is fingerprinted so it can be served immutable. Only the `latin` subsets are shipped. That range covers U+0000-00FF plus Œœ, smart punctuation and €, which is the whole of English and French — including œuvre and every accent in the fr translation. A language needing latin-ext, Greek or Cyrillic would need its subset added here. The two Instrument Serif faces are re-cut by tools/subset-fonts.py, which strips TrueType hinting and keeps every glyph — 31% smaller with identical coverage, advance widths and vertical metrics. See that script for why the character set is not cut instead. Set params.folio.remoteFonts = false to opt out entirely and fall back to the local stacks declared in tokens.css. */ -}} {{- $remote := true -}} {{- with site.Params.folio -}} {{- if isset . "remotefonts" -}} {{- $remote = .remoteFonts -}} {{- end -}} {{- end -}} {{- if $remote -}} {{- /* Inter ships as a single variable file covering the whole 100-900 axis, so 400/500/600 cost one download, not three. */ -}} {{- $inter := resources.Get "fonts/inter-latin-var.woff2" | fingerprint -}} {{- $serif := resources.Get "fonts/instrument-serif-latin.woff2" | fingerprint -}} {{- $serifItalic := resources.Get "fonts/instrument-serif-latin-italic.woff2" | fingerprint -}} {{- /* All three faces paint above the fold on every page: Inter for body, the serif for the headline, the italic for the wordmark. Fonts are always fetched in CORS mode, so crossorigin is required even same-origin or the preload is wasted and the file fetched twice. */ -}} {{- end -}}
